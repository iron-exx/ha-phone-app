### Plan 04-04: Phase 4 Exit Criteria — When Is Phase 4 "Done"?
**Task 1:** Checkliste ob Phase 4 als "fertig" betrachtet werden kann:
- [ ] Erstes Gerät nimmt an → alle anderen erhalten Cancel Push und hören auf zu klingeln
- [ ] Wenn keine Antwort innerhalb 30s → call_state → `cancelled`; alle Geräte erhalten missed-call Push
- [ ] Hold/Resume Übergänge funktionieren und Zustand ist konsistent über alle Geräte derselben Extension hinweg
- [ ] Zweites Gerät, das nach erstem Anruf antworten will, wird mit 409 Conflict abgelehnt und User sieht klares Feedback
- [ ] User-facing Diagnostics Seite zeigt alle required Fields (Push, SIP, Berechtigungen, Anrufe) mit aktuellem Status
- [ ] Admin-facing Dashboard zeigt Device-Status pro Extension mit Push/SIP/Zertifikat-Info
- [ ] History-Einträge werden gespeichert und können angezeigt werden
- [ ] Alle sub-tasks aus Plans 04-01 bis 04-04 sind "Done" (vollständig implementiert oder als Gap marked in 04-PHASE-SIGNOFF.md)

**Task 2:** Wenn alle Exit Criteria TRUE → Phase 4 sign-off schreiben in `04-PHASE-SIGNOFF.md` und Phase 5 (Tailscale Transport Hardening) in STATE.md und ROADMAP.md einleiten.
