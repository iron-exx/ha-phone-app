## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-01 | Tampering | `pjsip_extensions.conf.j2` endpoint stanza | mitigate | Never render `transport=` on the endpoint block (Pitfall 4) -- Asterisk auto-selects transport by arrival, avoiding a documented pjproject connection-issue class |
| T-2-02 | Information Disclosure | `/data/asterisk/tls/asterisk.key` | mitigate | `chmod 600` immediately after generation, matching the existing `ami_secret`/`session_secret` permission pattern in the same script |
| T-2-03 | Spoofing | Self-signed cert accepted by PJSUA2 clients | accept | Scoped explicitly to local-network-only dev testing per D-05; real cert trust is out of scope until a later production-transport phase (Phase 5) |
</threat_model>
