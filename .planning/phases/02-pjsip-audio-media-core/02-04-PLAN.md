```kotlin
                attributes,
                { /* onAnswer: log reportedAt / accepted */ },

                { /* onSetActive */ },
                { /* onSetInactive */ },
            ) {

```
The first lambda arg to `callsManager.addCall` is `onAnswer` -- fired by Telecom when the user answers via the system CallStyle notification action. This plan wires real SIP answer logic there -- and it MUST fire from there, not from the trailing `onRegistered` block, which runs as soon as Telecom finishes registering the call (essentially at push-arrival time, long before the user has done anything). `onRegistered`'s receiver type is `CallControlScope`, which exposes a suspend `disconnect()` -- the CR-01 precedent this plan's `SipCallController.answer` failure path must reuse; since `onAnswer` itself has no `CallControlScope` receiver, the live scope must be captured into a variable from inside the trailing block so `onAnswer` can reach it. This plan ALSO adds a `reportOutgoingCall` counterpart with `CallAttributesCompat.DIRECTION_OUTGOING` -- `addCall` is direction-agnostic (same Telecom API for both), so the shape is identical apart from the `direction` value and what happens inside the trailing lambda (answer vs. nothing -- the SIP INVITE for an outgoing call is sent by the caller of `reportOutgoingCall`, from inside its own `onRegistered` block, via `SipCallController.makeCall`).

    ```kotlin
    package de.haphone.app.test.sip

    /**
     * Client-side digit sanitization mirroring the server-side `_dial_string`
     * pattern in ~/projects/Ha-Phone/ha-phone/backend/routers/extensions.py
     * (Security V5 -- prevents SIP URI/header injection via a malformed
     * dialpad string, T-2-08). Reused for dial (CALL-03), DTMF (CALL-02),
     * and blind-transfer target entry (CALL-04) per D-12/D-13/D-14 -- one
     * function, three call sites.
     */
    object DialString {
        private val ALLOWED = Regex("[^0-9+*#]")

        fun sanitize(raw: String): String = ALLOWED.replace(raw, "")

        fun toSipUri(sanitized: String, domain: String): String {
            require(sanitized.isNotEmpty()) { "Cannot build a sip: URI with no digits" }
            return "sip:$sanitized@$domain;transport=tls"
        }
    }
    ```
