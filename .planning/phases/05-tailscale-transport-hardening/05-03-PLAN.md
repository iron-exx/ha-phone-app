# Phase 5: Tailscale Transport Hardening — Plan 03

**Wave:** 1 (third plan wave)
**Goal:** Implement the User-Facing Diagnostics screen for Tailscale status, and the Admin Dashboard integration for Tailscale connectivity monitoring and key management.

## Scope

This plan covers the user-visible and admin-visible diagnostics for the Tailscale transport layer. Users need to know whether Tailscale is active, whether the connection is healthy, and what to do if it's not. Admins need to manage Tailscale keys and view connectivity status across all provisioned devices.

## Plans within this Wave

### Plan 05-01 (continued): User-Facing Tailscale Diagnostics
**Task 1:** Add a "Tailscale" card to the User-facing Diagnostics screen (Plan 04-01).
- Task 2: Card shows current status: `connected` (with network type: WiFi / Cellular) / `disconnected` / `configuration error`.
- Task 3: "Status Refresh" Button — manually refreshes Tailscale status (re-runs `tailscale status` check).
- Task 4: "Configure Tailscale" Button — navigates to App Settings Tailscale field (or opens system settings).
- Task 5: Tooltip/Long-press text: "Tailscale verbindet das Telefon sicher mit Ihrer HA-Phone-Box über ein verschlüsseltes virtuelles Netzwerk. Es wird nur bei aktiven Anrufen verwendet — im Leerlauf nicht im Hintergrund."
- **Done when:** User sees Tailscale card in Diagnostics; status reflects actual Tailscale state; Buttons navigate correctly; Tooltip explains purpose.

### Plan 05-02: Admin Tailscale Dashboard Integration
**Task 1:** Add Tailscale status section to Admin Dashboard (Plan 04-02).
- Task 2: Section shows per-Device Tailscale status: `connected` / `disconnected` / `key expired` / `not configured`.
- Task 3: "Key Status" field: "gültig bis [Date]" or "Key fehlt — Bitte einrichten".
- Task 4: "Test Tailscale Connection" Button — triggers same check as User Diagnostics; result displayed per device.
- Task 5: "Key Rotieren" Button — clears stored key; next app launch prompts for re-entry (same as Dashboard remove key flow).
- **Done when:** Admin sees per-Device Tailscale status; Test Button works; Key Rotation clears key and prompts for re-entry.

### Plan 05-03: Tailscale Connection Health Indicators
**Task 1:** Add Tailscale health indicators to the Call Screen UI (during active call).
- Task 2: Top banner or status bar icon: `Tailscale: verbunden (WiFi)` / `Tailscale: verbunden (Mobilfunk)` / `Tailscale: nicht verbunden`.
- Task 3: Tapping the banner opens the User Diagnostics Tailscale card.
- Task 3: During call setup (before answer): grayed-out or "Tailscale: wartend" until call answered and Tailscale established.
- **Done when:** Call screen shows Tailscale status; Tapping opens Diagnostics; Before answer shows "wartend"; After answer shows connected status.

### Plan 06-03: Tailscale Key Expiration & Rotation Handling
**Task 1:** Detect key expiration — Tailscale SDK or `tailscale status` returns key expired error.
- Task 2: UI updates: Card status changes to `key expired`; "Key rotieren" button enabled; "Configuration error" tooltip updated.
- Task 2: User taps "Key rotieren" → stored key cleared; next app launch prompts for new Key entry (same as Plan 05-01 Plan 4).
- Task 3: While key expired: Tailscale transport disabled; call falls back to STUN/TURN (if configured); Diagnostics shows "Tailscale aus — STUN/TURN aktiviert".
- **Done when:** Key expiration detected; UI updates; User can rotate key; Fallback to STUN/TURN works.

### Plan 07-04: Diagnostics History — Tailscale Connection Log
**Task 1:** Store Tailscale connection events locally (UserDefaults/iCloud/SQLite) with: Timestamp, Event (connect/ disconnect/ key_rotated/ handoff), Outcome (success/ failed/ key_expired), Network type (WiFi/ Cellular).
- Task 2: In Diagnostics: "Tailscale-Verlauf" section — last 5 events listed with Timestamp + Outcome + Network.
- Task 3: "Alle löschen" Button — clears local Tailscale history.
- **Done when:** Events stored locally; History appears in Diagnostics; Delete function works.

## Exit Criteria

- User-facing Diagnostics: Tailscale card shows correct status; Buttons navigate/function
- Admin Dashboard: per-Device Tailscale status displayed; Test/Rotate buttons work
- Call Screen: Tailscale status banner shows correct state; Tapping opens Diagnostics
- Key expiration: detected; UI updates; Rotation flow works; Fallback to STUN/TURN enabled
- History: events stored; appear in Diagnostics; can be cleared
